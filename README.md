# Homebrew tap

Casks for [Burnline](https://github.com/igharsha7/Burnline-AI-Usage-Tracker),
a menu-bar app and dashboard for AI coding usage, plan limits and what that
usage would cost at API prices.

```sh
brew install --cask igharsha7/tap/burnline
```

Burnline is not notarized, so macOS stops it the first time it opens. Open
it once, then choose **Open Anyway** in **System Settings → Privacy &
Security**. Updates install from within Burnline.

The cask is generated by Burnline's release workflow from
[`.github/homebrew/burnline.rb`](https://github.com/igharsha7/Burnline-AI-Usage-Tracker/blob/main/.github/homebrew/burnline.rb)
in the main repository, and pushed here with each release. Change it there,
not here.
